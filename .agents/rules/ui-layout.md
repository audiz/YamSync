# Adaptive & Compact UI Guidelines (Compose Multiplatform)

Развивать интерфейс строго в существующем стиле проекта (как в `HomeHub.kt`, `PlayerBar.kt`, `MobilePlayer.kt`):

## 1. Адаптивность (Desktop + Mobile)
- **Автоматический перенос элементов (FlowRow / FlowColumn)**:
  - Любые группы горизонтальных элементов (чипы фильтров, категории, теги, плитки быстрого доступа, папки) должны оборачиваться во `FlowRow` с `Arrangement.spacedBy(8.dp)` или `(10.dp)`.
  - Элементы ни при каких условиях не должны обрезаться или уходить за правый край экрана на смартфонах — они должны органично переезжать на новую строку.
- **Брейкпоинты и BoxWithConstraints**:
  - Использовать `BoxWithConstraints` для проверки ширины (стандартный брейкпоинт в проекте: `isWide = maxWidth >= 540.dp`).
  - Учитывать флаг платформы `isMobileUi`: на смартфонах скрывать второстепенный оверлей или переносить управление в нижний sheet/бар, на десктопе сохранять горизонтальные расширенные панели.
- **Никаких фиксированных ширин экрана**: Использовать `fillMaxWidth()`, `weight(...)`, либо адаптивные ограничения (`widthIn`, `sizeIn`).

## 2. Компактность и визуальный стиль проекта
- **Плотность информации**:
  - Отступы внутри карточек и списков: 8.dp – 12.dp (избегать избыточных `padding(16.dp+)` на экранах контента).
  - Шрифты: `titleSmall`, `bodySmall` с уменьшенным размером (`11.sp` – `12.sp`) для вторичных подписей.
  - Длинные строки (названия треков, артисты, пути): всегда сопровождать `maxLines = 1` и `overflow = TextOverflow.Ellipsis`.
- **Дизайн компонентов**:
  - Карточки: `RoundedCornerShape(12.dp)` или `16.dp`, тонкая рамка `BorderStroke(1.dp, MaterialTheme.colorScheme.outlineVariant.copy(alpha = 0.4f))`.
  - Фон интерактивных блоков: мягкие градиенты `Brush.linearGradient` с прозрачностями темы (`primary.copy(alpha = 0.08f–0.16f)`).
- **Поддержка мыши и сенсорного ввода**:
  - Для всех кликабельных элементов на Desktop обязательно указывать `.pointerHoverIcon(PointerIcon.Hand)`.
  - На мобильных устройствах не делать кликабельные иконки физически меньше 36–40dp для удобного нажатия пальцем.
