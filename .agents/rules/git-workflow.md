# Git Workflow Rules

## 1. Коммиты (Commits)
- **Обязательные локальные коммиты**: После успешного выполнения логически завершённой задачи или этапа работы необходимо фиксировать изменения в локальный Git (`git commit`).
- **Понятные сообщения коммитов**: Сообщения должны быть информативными и отражать суть внесённых изменений (желательно на русском или английском в формате Conventional Commits, например: `feat: ...`, `fix: ...`, `refactor: ...`).
- **Чистота коммитов**: Не добавлять в коммит временные файлы, логи, артефакты сборки или конфиги с персональными данными.

## 2. Запрет на Push
- **Никогда не делать `git push`**: Отправка изменений в удалённый репозиторий запрещена.
- Все коммиты должны оставаться строго локальными — решение о пуше в remote принимает исключительно пользователь вручную.
