Что изменилось: правый блок кнопок теперь центрирован по высоте карточки, а не по строке заголовка. Все четыре варианта используют один каркас, поэтому переключаются без изменения логики. Выберите характер — внедрю в LocalPlaylistsTab и YandexUserPlaylistsTab.
