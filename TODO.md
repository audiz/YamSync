## 🚀 Функциональность и возможности (Features)

- [ ] **Пакетная (массовая) загрузка плейлистов и альбомов**
  - Кнопка «Скачать весь альбом / плейлист» в один клик.
  - Индикатор суммарного прогресса и параллельная очередь загрузки.
- [ ] **Экспорт и импорт плейлистов**
  - Экспорт сохраненных треков в файл плейлиста формата `.m3u8` для открытия во внешних плеерах (AIMP, VLC и др.).
- [ ] **Отображение текстов песен (Lyrics)**
  - Интеграция API текстов песен Яндекс Музыки (включая синхронизированные строки в режиме караоке).
  - Панель с текстом текущего трека в плеере.
- [ ] **Нормализация громкости (ReplayGain)**
  - Автоматическое выравнивание громкости между треками для предотвращения резких перепадов.
- [ ] **Кастомизация структуры папок сохранения**
  - Настройка маски пути в настройках приложения: `{Artist}/{Album}/{TrackNumber} - {Title}.mp3`.
- [ ] **Поддержка Lossless / FLAC**
  - Загрузка аудиопотока в оригинальном студийном качестве (FLAC) при наличии подписки Яндекс Плюс.
